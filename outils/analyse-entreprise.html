Hypothèses

  • Les trois sociétés proposées sont fictives, leurs chiffres inventés pour illustrer trois profils : croissance endettée, industriel en difficulté, valeur stable.
  • Le levier est mesuré par la dette nette divisée par le résultat opérationnel, faute d'EBITDA dans le tableau : c'est plus sévère que le ratio habituel.
  • Les repères sont des ordres de grandeur généraux. Une banque, une foncière ou une société de logiciels se lisent avec d'autres repères.

La formule

Valeur = Σ FCF × (1 + g)ᵗ / (1 + r)ᵗ + valeur terminale − dette nette
Valeur terminale = FCF₁₀ × (1 + g∞) / (r − g∞), actualisée

PER = cours / bénéfice par action. Taux de distribution = dividendes versés / résultat net. ROE = résultat net / capitaux propres.
